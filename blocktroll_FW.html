프로젝트 개요

이게 뭘 하는 프로젝트인가요?

복잡한 기술 없이도 이해할 수 있도록, 핵심 기능과 방식을 한눈에 정리했습니다.

💬

YouTube 댓글을 읽습니다

Chrome 확장 프로그램이 유튜브 댓글 페이지를 감지하고, 화면에 표시된 댓글 목록을 수집합니다. 사용자가 별도로 버튼을 누를 필요 없습니다.

🧠

내 PC에서 AI가 판단합니다

수집된 댓글은 인터넷이 아닌 내 컴퓨터 안에서 실행되는 AI 서버로 전송됩니다. 개인 정보가 외부로 나가지 않습니다.

🔍

AI + 규칙이 함께 작동합니다

딥러닝 모델과 사전에 정의된 필터 규칙을 같이 사용하는 하이브리드 구조입니다. 속도와 정확도를 모두 챙깁니다.

🙈

위험한 댓글을 가려줍니다

분석 결과에 따라 악성 댓글은 흐릿하게 처리(Blur)하거나 아예 숨깁니다(Hide). 원하면 클릭해서 확인할 수 있습니다.

핵심 기능

3가지 댓글 유형을 분류합니다

각 유형은 서로 다른 방식으로 탐지되고, 상황에 맞게 처리됩니다.

TOXIC 🚫

악성 댓글

욕설, 혐오 표현, 인신공격 등 명백히 해로운 표현을 포함한 댓글입니다. AI 모델과 키워드 필터를 함께 사용해 높은 정확도로 탐지합니다.

예시 (처리 후)
야 이 ㅂㅅ아 꺼져라 진짜 ㅈㄹ하고 있어
AI 모델 룰 기반 Blur / Hide
SPAM 🗑️

스팸 댓글

광고, 홍보 링크, 반복적인 홍보성 문구 등 실질적인 의미가 없는 댓글입니다. 패턴 기반 룰 엔진의 비중이 큰 유형입니다.

예시 (처리 후)
팔로우 하면 맞팔 ㄱ! 구독자 늘리는 법 t.me/xxxx
룰 기반 주도 링크 탐지 Hide
TAUNT 😏

비꼼 / 조롱

직접적인 욕설은 없지만 비아냥, 조롱, 빈정거림이 담긴 댓글입니다. 문맥 파악이 중요해 룰과 AI가 함께 사용됩니다.

예시 (처리 후)
와 진짜 대단하시네요^^ 이런 분들이 계속 활동하시다니
AI 모델 패턴 룰 Blur
개발 구조

시스템을 구성하는 5가지 요소

각 구성 요소가 어떤 역할을 맡고 있는지, 비개발자도 이해할 수 있도록 설명합니다.

🧩
Chrome Extension
Frontend

유튜브 화면을 감시하고 댓글을 수집합니다. 분류 결과를 받아 댓글을 숨기거나 흐리게 처리합니다.

⚡
FastAPI Server
Local Backend

로컬 PC에서 실행되는 중간 서버입니다. 확장 프로그램의 요청을 받아 AI와 룰 엔진에 전달하고 결과를 반환합니다.

🧠
AI Inference
Model Engine

한국어 텍스트를 분석하도록 학습된 AI 모델이 댓글의 독성 여부를 판단합니다. 주로 TOXIC 분류에 활용됩니다.

📋
Rule Engine
Filter Logic

사전에 정의된 패턴과 키워드로 빠르게 판단합니다. 스팸과 비꼼 댓글에 특히 효과적이며, AI보다 속도가 빠릅니다.

🏋️
Training Pipeline
Separate Env

AI 모델을 더 똑똑하게 만드는 학습 과정입니다. 현재는 구조만 설계된 상태이며, 실제 학습은 별도 환경에서 진행됩니다.

더 커질 수 있는 가능성

현재는 로컬 실행형 MVP입니다. 이후 단계에 따라 다양한 방향으로 확장할 수 있습니다.

☁️

서버형 배포

팀 단위·서비스 형태로 발전 시 클라우드 서버에 배포하는 구조로 전환할 수 있습니다.

🤖

대형 한국어 모델

더 큰 한국어 악플 분류 모델을 적용해 비꼼, 맥락적 독성 탐지 정확도를 높입니다.

🌐

플랫폼 확장

YouTube 외에 네이버 뉴스, 트위터(X), 카카오 등 다른 댓글 플랫폼으로 필터 범위를 확대합니다.

🎛️

사용자 설정 고도화

개인별 민감도, 허용 키워드 설정, 화이트리스트/블랙리스트 등 세부 커스터마이징 기능을 추가합니다.

개발 프로세스

어떻게 만들어졌나요?

문제를 발견하고 해결책을 만들어가는 개발의 흐름을 단계별로 정리했습니다.

Step 01
문제 정의
유튜브 댓글의 악플·스팸 문제를 직접 경험하고, 클라우드 없이 로컬에서 처리할 수 있는 필터 시스템의 필요성을 정의했습니다.
Step 02
프로토타입 제작
Chrome Extension과 간단한 로컬 서버를 연결하는 최소 프로토타입을 제작했습니다. 댓글 수집 → 처리 → 화면 반영의 흐름을 검증했습니다.
Step 03
룰 기반 필터 구축
스팸 링크, 반복 패턴, 특정 키워드를 기반으로 빠르게 동작하는 규칙 엔진을 먼저 구현했습니다. 즉각적인 탐지 속도를 확보했습니다.
Step 04
AI 모델 연결
한국어 텍스트를 처리할 수 있는 딥러닝 모델을 로컬 서버에 연결했습니다. TOXIC 분류에 AI 추론이 적용되기 시작했습니다.
Step 05
하이브리드 구조 설계
AI 모델과 룰 엔진의 역할을 분리해 하이브리드 구조를 설계했습니다. TOXIC은 모델 주도, SPAM·TAUNT는 룰 비중을 높이는 방향으로 최적화했습니다.
Step 06 (진행 중)
성능 및 정확도 개선
분류 속도 최적화, 모델 고도화, 사용자 피드백 반영을 통한 정확도 개선이 현재 진행 중입니다. 모델 재학습 파이프라인도 설계 중입니다.
